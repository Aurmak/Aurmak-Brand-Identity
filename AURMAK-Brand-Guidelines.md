# AURMAK Brand Identity Guidelines v1.0

## Document Overview
This comprehensive brand identity guideline document defines the visual language, design principles, and implementation standards for AURMAK, a hybrid venture studio operating at the intersection of technology and strategic capital deployment.

---

## 1. Brand Overview

### Brand Positioning
AURMAK is a **hybrid venture studio** that combines strategic capital deployment with hands-on venture building. We operate at the intersection of:
- **Strategic Investment**: Capital allocation driven by deep technical and market analysis
- **Venture Building**: Hands-on creation and scaling of technology-driven businesses
- **Operational Excellence**: Engineering-first approach to business creation

### Brand Attributes
- **Authoritative**: Enterprise-grade credibility and institutional trust
- **Technical**: Engineering-first, data-driven decision making
- **Precision-focused**: Obsessive attention to detail and systematic execution
- **Future-oriented**: Building infrastructure for tomorrow's economy
- **Understated**: Confident without being ostentatious

### Design Philosophy
The AURMAK visual identity is inspired by **Palantir's design language** — a corporate, minimalist, high-tech aesthetic that prioritises:
- Clean, grid-based layouts with abundant whitespace
- Sharp, precise visual hierarchy
- Enterprise-grade professionalism (not playful or startup-like)
- Technical diagrams and data visualisation
- Sophisticated colour restraint
- Institutional credibility

## 2. Logo Guidelines

### Logo Construction
The AURMAK wordmark is the primary brand identifier. It features:
- Custom letterforms with technical precision
- Consistent spacing and optical balance
- Available in full-colour, monochrome, and reverse variants

### Primary Logo Variants
1. **Full Colour Logo**: Navy (#1B2A6B) wordmark with Cyan (#2CB5E3) accent
2. **Monochrome Dark**: All-Navy (#1B2A6B) for light backgrounds
3. **Monochrome Light**: White/reversed for dark backgrounds
4. **Single Colour Cyan**: Cyan (#2CB5E3) for special applications

### Clear Space Requirements
- Minimum clear space: **X-height of the letter 'A'** on all sides
- Never place other design elements or text within this protected zone
- Ensures visual breathing room and brand recognition

### Minimum Size Standards
- **Digital/Screen**: Minimum 120px width
- **Print**: Minimum 25mm width
- Never scale below these dimensions to maintain legibility

### Logo Do's
✓ Use approved logo files only  
✓ Maintain minimum clear space on all sides  
✓ Use on backgrounds with sufficient contrast  
✓ Scale proportionally (lock aspect ratio)  
✓ Use monochrome version when colour is limited  

### Logo Don'ts
✗ Do not rotate, skew, or distort the logo  
✗ Do not apply gradients, shadows, or effects  
✗ Do not change the logo colours  
✗ Do not place on busy or low-contrast backgrounds  
✗ Do not recreate or retype the logo  
✗ Do not scale below minimum size requirements

## 3. Colour System

### Primary Palette

#### Deep Navy Blue
- **Hex**: `#1B2A6B`
- **RGB**: 27, 42, 107
- **CMYK**: 75, 61, 0, 58
- **Pantone**: 2765 C (closest match)
- **Usage**: Primary text, headings, authoritative UI elements, dark backgrounds
- **Accessibility**: WCAG AA compliant on white backgrounds

#### Bright Cyan
- **Hex**: `#2CB5E3`
- **RGB**: 44, 181, 227
- **CMYK**: 81, 20, 0, 11
- **Pantone**: 306 C (closest match)
- **Usage**: Accent colour, interactive elements, call-to-action buttons, data visualisation highlights
- **Accessibility**: Use with caution on white; ensure 4.5:1 contrast for text

### Secondary Palette

#### Charcoal Grey
- **Hex**: `#4A5568`
- **RGB**: 74, 85, 104
- **Usage**: Body text, secondary information, subdued UI elements

#### Light Grey (Background)
- **Hex**: `#F4F6F8`
- **RGB**: 244, 246, 248
- **Usage**: Page backgrounds, card backgrounds, subtle separators

#### Border Grey
- **Hex**: `#E5E7EB`
- **RGB**: 229, 231, 235
- **Usage**: Borders, dividers, subtle visual separators

#### Pure White
- **Hex**: `#FFFFFF`
- **RGB**: 255, 255, 255
- **Usage**: Primary backgrounds, card surfaces, text on dark backgrounds

#### Pure Black
- **Hex**: `#000000`
- **RGB**: 0, 0, 0
- **Usage**: Maximum contrast situations (use sparingly)

### Colour Usage Principles
- **Hierarchy**: Navy for primary, Cyan for accent/interaction
- **Contrast**: Always maintain WCAG AA (4.5:1) minimum for text
- **Restraint**: Use colour purposefully, not decoratively
- **Consistency**: Apply colours systematically across all touchpoints

### Accessibility Standards
- **Text on White**: Navy (#1B2A6B) passes WCAG AAA
- **Interactive Elements**: Cyan (#2CB5E3) minimum 3:1 for large text
- **Focus States**: Ensure visible focus indicators for keyboard navigation
- **Print**: Test all colour combinations for colour-blind accessibility

## 4. Typography System

### Primary Typeface: Inter

**Inter** is a highly legible sans-serif typeface designed for user interfaces and digital screens. It features:
- Excellent readability at small sizes
- Neutral, professional character
- Open-source and widely available
- Extensive weight range (100-900)

### Font Weights & Usage

#### Inter Black (900)
- **Usage**: Large display headings, hero text
- **Size Range**: 48px - 72px+
- **Line Height**: 1.1
- **Letter Spacing**: -0.02em (tight tracking for large sizes)

#### Inter Bold (700)
- **Usage**: Section headings (H2, H3), emphasis text
- **Size Range**: 24px - 36px
- **Line Height**: 1.3
- **Letter Spacing**: -0.01em

#### Inter Semi-Bold (600)
- **Usage**: Subheadings (H4), UI labels, navigation
- **Size Range**: 16px - 20px
- **Line Height**: 1.4
- **Letter Spacing**: 0

#### Inter Medium (500)
- **Usage**: Body emphasis, button text, list items
- **Size Range**: 14px - 18px
- **Line Height**: 1.5
- **Letter Spacing**: 0

#### Inter Regular (400)
- **Usage**: Body copy, paragraph text, descriptions
- **Size Range**: 14px - 18px
- **Line Height**: 1.6
- **Letter Spacing**: 0

### Typography Hierarchy

```
H1 (Page Title)
- Font: Inter Black (900)
- Size: 48px
- Colour: #1B2A6B
- Line Height: 1.1
- Use Case: Primary page headings

H2 (Section Heading)
- Font: Inter Bold (700)
- Size: 28px - 32px
- Colour: #1B2A6B
- Line Height: 1.3
- Use Case: Major section divisions

H3 (Subsection Heading)
- Font: Inter Bold (700)
- Size: 20px - 24px
- Colour: #1B2A6B
- Line Height: 1.4
- Use Case: Content subsections

H4 (Component Heading)
- Font: Inter Semi-Bold (600)
- Size: 16px - 18px
- Colour: #1B2A6B
- Line Height: 1.4
- Use Case: Card titles, component labels

Body Text
- Font: Inter Regular (400)
- Size: 16px
- Colour: #4A5568
- Line Height: 1.6
- Use Case: Paragraphs, descriptions

Small Text / Captions
- Font: Inter Regular (400)
- Size: 12px - 14px
- Colour: #4A5568
- Line Height: 1.5
- Use Case: Metadata, captions, footnotes
```

### Typography Principles
- **Hierarchy**: Use size, weight, and colour to establish clear information hierarchy
- **Readability**: Maintain generous line height (1.5-1.6) for body text
- **Consistency**: Limit to 3-4 type sizes per layout
- **Alignment**: Left-align text for maximum readability; center only for display purposes

## 5. Visual Direction

### Photography Style

#### Corporate Environment Photography
- **Subject Matter**: Professional office environments, modern workspace interiors, technology infrastructure
- **Tone**: Clean, professional, aspirational but authentic
- **Lighting**: Natural light, bright and airy, minimal shadows
- **Composition**: Wide angles, architectural precision, geometric clarity
- **Colour Grading**: Cool tones, slightly desaturated, professional colour balance
- **People**: Candid shots (not posed), diverse professionals in modern work environments

#### Image Characteristics
- **High-quality**: Professional photography only, minimum 1920px width
- **Authentic**: Real office environments, not overly staged stock imagery
- **Geometric**: Clean lines, architectural elements, spatial balance
- **Technology-focused**: Screens, devices, data visualisation when appropriate
- **Minimal clutter**: Clean, organised spaces that reflect operational excellence

### Mood Board Keywords
- "Modern office architecture natural light"
- "Professional workspace minimalist"
- "Tech company headquarters interior"
- "Contemporary business environment"
- "Data centre technology infrastructure"
- "Enterprise software development team"

### Graphic Elements

#### Grid Systems
- **8-point grid**: All spacing and sizing based on multiples of 8px
- **Column grids**: 12-column layout for responsive design
- **Gutters**: Minimum 24px between content blocks

#### Iconography
- **Style**: Line icons, minimal, geometric
- **Weight**: 2px stroke weight for consistency
- **Library**: Lucide React or custom technical icons
- **Colour**: Navy (#1B2A6B) or Cyan (#2CB5E3) only

#### Data Visualisation
- **Charts**: Clean, minimal styling with clear labels
- **Colours**: Use primary palette (Navy + Cyan) with grey accents
- **Library**: Recharts for React applications
- **Accessibility**: Always include text alternatives and legends

## 6. UI Components & Design System

### Component Library: Ant Design 6.3.0

AURMAK uses **Ant Design (AntD) 6.3.0** as the primary enterprise UI library, customised with brand tokens.

### Theme Configuration

```javascript
import { ConfigProvider } from 'antd';

<ConfigProvider
  theme={{
    token: {
      colorPrimary: '#2CB5E3',      // Bright Cyan
      colorInfo: '#2CB5E3',          // Info states
      colorTextBase: '#1B2A6B',      // Primary text colour
      fontFamily: 'Inter, sans-serif'
    },
    components: {
      Button: {
        colorPrimary: '#2CB5E3',
        colorPrimaryHover: '#1B9BC4'
      }
    }
  }}
>
  {/* Your app components */}
</ConfigProvider>
```

### Spacing System (8pt Grid)

```
4pt  = 1 (Tailwind: space-1)
8pt  = 2 (Tailwind: space-2)
16pt = 4 (Tailwind: space-4)
24pt = 6 (Tailwind: space-6)
32pt = 8 (Tailwind: space-8)
48pt = 12 (Tailwind: space-12)
64pt = 16 (Tailwind: space-16)
```

- **Default Components**: 8px (AntD 6.3 default) — buttons, inputs, cards
- **Full Rounded**: 9999px — badges, pills, status indicators
- **Sharp (Special Cases)**: 2px — technical diagrams, data tables

## 7. Tone of Voice

### Brand Voice Attributes

#### Professional
- Use industry-standard terminology
- Avoid jargon unless speaking to technical audiences
- Maintain grammatical precision
- Use British English spelling (colour, organisation, capitalise)

#### Confident
- Make definitive statements backed by data
- Avoid hedging language ("perhaps", "maybe", "we think")
- Use active voice over passive
- Example: "We build ventures" not "Ventures are built by us"

#### Precise
- Use specific data points and metrics
- Avoid vague qualifiers ("very", "quite", "really")
- Choose exact words over approximations
- Example: "£2.4M deployed" not "approximately £2M+"

#### Technical
- Comfortable with technical language when appropriate
- Explain complex concepts with clarity
- Use data and evidence to support claims
- Balance technical depth with accessibility

#### Authoritative (Not Arrogant)
- Demonstrate expertise through insight, not boasting
- Focus on outcomes and results
- Give credit where due
- Avoid superlatives unless substantiated

### Writing Guidelines

#### Headlines & Titles
- Short, punchy, declarative
- Use sentence case (not title case)
- No full stops at the end
- Example: "Building ventures that scale infrastructure"

#### Body Copy
- Keep sentences under 25 words
- One idea per paragraph
- Use lists and bullet points for clarity
- Front-load important information

#### Calls-to-Action
- Use action verbs
- Be specific about what happens next
- Examples:
  - ✓ "Schedule a consultation"
  - ✗ "Learn more"

#### Technical Content
- Define acronyms on first use
- Use code blocks for technical examples
- Include context for technical readers and non-technical stakeholders
- Link to additional resources for deeper dives

### British English Standards

#### Spelling
- colour (not color)
- organisation (not organization)
- capitalise (not capitalize)
- analysed (not analyzed)
- programme (not program, except for computer programs)
- centre (not center)

#### Punctuation
- Use single quotation marks for quotes
- Place punctuation outside quotes (unless part of the quoted material)
- Use Oxford comma for clarity in lists
- Use en-dash (–) for ranges, em-dash (—) for breaks

#### Date Format
- DD Month YYYY (21 February 2026)
- Avoid MM/DD/YYYY format

#### Numbers
- Spell out numbers one to nine
- Use numerals for 10 and above
- Use commas for thousands (1,000 not 1000)
- Use "per cent" not "%" in body copy (% acceptable in tables/charts)

### Content Examples

#### ✓ Good Example
"AURMAK deployed £2.4M across three ventures in Q4 2025, focusing on infrastructure software and enterprise tooling. Each venture underwent rigorous technical due diligence and market validation before capital allocation."

#### ✗ Poor Example  
"AURMAK has deployed approximately $2M+ across some really cool ventures recently. We're super excited about the infrastructure space and think it's going to be huge!"

## 8. Layout & Grid Principles

### Page Structure

#### Maximum Content Width
- **Desktop**: 1280px maximum width
- **Centered**: Content centered with equal margins
- **Padding**: Minimum 32px horizontal padding on container

#### Responsive Breakpoints
```
Mobile:  320px - 767px
Tablet:  768px - 1023px
Desktop: 1024px - 1279px
Wide:    1280px+
```

#### Vertical Rhythm
- **Section Spacing**: 64px - 96px between major sections
- **Content Spacing**: 24px - 32px between content blocks
- **Element Spacing**: 16px between related elements
- **Line Spacing**: 8px between list items

### Whitespace Principles

- **Generous**: Use whitespace liberally to create breathing room
- **Purposeful**: Whitespace creates visual hierarchy and grouping
- **Consistent**: Maintain consistent spacing patterns throughout
- **Asymmetric**: Don't be afraid of unequal margins for visual interest

### Grid Layout

#### 12-Column Grid
- **Columns**: 12 equal-width columns
- **Gutter**: 24px between columns
- **Margin**: 32px minimum on sides

#### Common Layouts
- **Full Width**: 12 columns (hero sections, images)
- **2 Column**: 6/6 split (equal content blocks)
- **Sidebar**: 8/4 or 9/3 split (main content + sidebar)
- **3 Column**: 4/4/4 split (features, team, services)
- **4 Column**: 3/3/3/3 split (stats, benefits, icons)
